# Synchus stage demo kit

These files contain realistic but synthetic logistics records made for the Synchus demo. They are not production facts.

Upload them from **Inbox → Company documents** in this order:

1. `01_route_disruption_report.txt` — a complete ground report that should stage ordinary operational context.
2. `02_cold_chain_readings.csv` — a repeated structured data shape that should make the agent consider a new cold-chain capability.
3. `03_yard_snapshot.json` — a hub inventory snapshot that demonstrates the difference between uploaded point-in-time evidence and a live yard feed.
4. `04_client_gate_change.md` — a durable client operating rule with an effective date and source.

Each file is intentionally explicit about source, time, location, and scope so the audience can see that Synchus preserves evidence rather than inventing certainty.
